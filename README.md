# LongTake: Long-Horizon Continuation in Autoregressive Video Diffusion

Byoungwoo Park, Jaemoo Choi, Juho Lee, and Yongxin Chen.

KAIST and Georgia Institute of Technology. Juho Lee and Yongxin Chen contributed equal advising.

Project page: https://bw-park.github.io/LongTake/

Serve this directory over HTTP and open index.html. Videos, figures, fonts, and playback libraries are included locally.

The page includes 30-second and 60-second galleries, matched comparisons, teacher comparisons, and the conditional-guidance ablation. Videos play while visible and pause off screen; manual pause, playback-speed controls, and seeking are available.

Third-party playback-library license: assets/vendor/hls-LICENSE.txt.
